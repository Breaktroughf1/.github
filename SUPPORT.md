# Getting help

| You want to… | Go here |
|---|---|
| Ask how to use a package | [Discussions → Q&A](https://github.com/orgs/Breaktroughf1/discussions/categories/q-a) |
| Suggest a feature | [Discussions → Ideas](https://github.com/orgs/Breaktroughf1/discussions/categories/ideas) |
| Report a reproducible bug | An issue in that project's repository, for example [flutter_mfa issues](https://github.com/Breaktroughf1/flutter_mfa/issues) |
| Report a security vulnerability | **Privately**, via [flutter_mfa security advisories](https://github.com/Breaktroughf1/flutter_mfa/security/advisories/new). Never in a public issue or discussion. |
| Hire us or talk about a project | [breaktroughf1.com/contact](https://breaktroughf1.com/contact) |

Maintainers answer Discussions on working days, usually within two of them. Package documentation is on [pub.dev](https://pub.dev/publishers/breaktroughf1.com/packages).
